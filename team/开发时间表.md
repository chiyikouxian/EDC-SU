## 接口约定

三人尽早对齐以下接口，避免联调时出问题。

### 陈→苏（视觉到主控，串口）

```
格式: $SHAPE,TARGET,VALID\r\n
示例: $CIRCLE,A,1\r\n      // 识别到圆形，目标A，有效
      $NONE,X,0\r\n        // 未识别到图形
```

| 字段 | 取值 |
|------|------|
| SHAPE | CIRCLE / TRIANGLE / RECT / PENTAGON / NONE |
| TARGET | A / B / C / D / X |
| VALID | 1=连续多帧确认 / 0=未确认 |

### 苏→陈（主控到视觉，串口）

| 命令 | 含义 |
|------|------|
| `$CMD,FIXED_DETECT\r\n` | 基础导航：开始固定角度识别 |
| `$CMD,SCAN_READY\r\n` | 发挥模式：云台到位，请识别当前画面 |
| `$CMD,STOP_DETECT\r\n` | 停止识别 |

### 苏→沈（主控到底盘）

如果主控和底盘是同一块板，则为函数调用；如果分板则串口。

| 命令/函数 | 含义 |
|-----------|------|
| `motor_lock()` | 锁死电机 |
| `motor_unlock()` | 解锁电机 |
| `find_line()` | 原地找线 |
| `follow_line(target)` | 循迹行驶到目标点，target=A/B/C/D |
| `stop()` | 立即停车 |

### 沈→苏（底盘到主控）

| 回调/状态 | 含义 |
|-----------|------|
| `LINE_FOUND` | 已找到黑线 |
| `TARGET_REACHED` | 已到达目标点 |
| `LINE_LOST` | 丢线 |
